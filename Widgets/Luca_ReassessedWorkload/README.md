# Project Controlling Widget (AVENIQ-20251219-01)

## Build

The first time: `npm install` to install all the packages used 

```bash
npm run build_js
```

File to be deployed: `script.js` this is the resulting file ( to be copied into the sandbox) ( basically takes all the src typescript files and generates one javascript file)


## Test

Tests can be run with `npm test`
